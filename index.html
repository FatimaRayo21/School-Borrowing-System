About Us

Welcome to the Pasig Knowledge Center Borrowing System .


The Pasig Knowledge Center Borrowing System is a user-friendly web-based system designed to make borrowing and returning resources more organized and efficient.
It allows users to easily search for items, check available equipment, and keep track of borrowing history. The system aims to provide a convenient way for users and the Knowledge Center
to manage resources while ensuring that items are properly monitored and available when needed.



How it works

Guidelines to borrow easily


Search for the items


Search for the book or resource you need and check if it is available.

Borrow Item


Select the item and complete the borrowing process.

Return Item


Return the borrowed item on or before its due date.

Search Item

Search for an item that you want to borrow.
